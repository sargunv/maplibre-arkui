The API reference of `@maplibre/arkui`, grouped by feature. Components and
classes show their ArkUI decorators as badges, such as `@Param`.

## Components

- The map: {@link MaplibreMap}.
- Control presets: {@link DefaultControls}, {@link FullControls}, and {@link
  AttributionControls}.
- Controls: {@link AttributionButton}, {@link AttributionText}, {@link
  CompassButton}, {@link DisappearingCompassButton}, {@link
  DisappearingScaleBar}, {@link MaplibreLogo}, {@link ScaleBar}, and {@link
  ZoomButtons}.
- Markers: {@link Marker}, {@link OffscreenMarker}, and {@link
  PointerPinButton}.
