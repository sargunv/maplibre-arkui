The API reference of `@maplibre/arkui`, generated from the library's doc
comments. Struct components and classes show their ArkUI decorators as badges,
such as `@Param` for a component's params. The reference lists the declarations
by feature, in the order of the guides.

## Components

- {@link MaplibreMap}, the map.
- The overlay presets: {@link DefaultControls}, {@link FullControls}, and {@link
  AttributionControls}.
- The controls: {@link AttributionButton}, {@link CompassButton}, {@link
  DisappearingCompassButton}, {@link DisappearingScaleBar}, {@link
  MaplibreLogo}, {@link ScaleBar}, and {@link ZoomButtons}.
- The markers: {@link Marker}, {@link OffscreenMarker}, and {@link
  PointerPinButton}.
