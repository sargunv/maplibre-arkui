MapLibre ArkUI shows interactive maps in ArkUI apps on HarmonyOS and
OpenHarmony. You add a <Api of="MaplibreMap" /> component to a page, move its
camera with a <Api of="MapController" />, and declare your own data from your
app's state. The maps render with [MapLibre Native], an open-source map engine,
and work with any map style and tiles that MapLibre can load.

MapLibre ArkUI is built on [MapLibre Native FFI]. Its sibling library,
[MapLibre Compose], brings the same engine to Compose Multiplatform.

## Status

The library is a preview and isn't on [ohpm] yet ([#26]). Until version 1.0, a
release can contain breaking changes.
