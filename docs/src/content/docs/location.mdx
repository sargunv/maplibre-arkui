The map draws the location that you pass as its
<Api of="MaplibreMap.userLocation" display="userLocation" />: a dot in a circle
that shows the location's accuracy.

## Show the location

Get locations from Location Kit, and pass each one to the map. Your app asks for
the location permission itself:

<Code code={region(location, "location")} lang="ts" />

## Follow the user

<Api of="MapController.followUserLocation" display="followUserLocation()" /> moves
the camera to the location, and then with each new one, until the user pans.
This button shows while the camera isn't following:

<Code code={region(location, "follow")} lang="ts" />

## Show the heading

To show where the device faces, pass the compass direction as the map's
`userHeading`. To turn the map with it, follow with `FollowBearing.HEADING`:

<Code code={region(location, "heading")} lang="ts" />

## Style the location indicator

<Api of="UserLocationIndicatorOptions" /> changes the indicator's colors and
images, and places it under other layers. This indicator is red and draws under
the style's labels:

<Code code={region(location, "indicator")} lang="ts" />
