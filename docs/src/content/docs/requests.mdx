These are [MapLibre Native FFI]'s API, which the package re-exports. Maps and
snapshots share a default runtime unless the app passes its own. Set request
handlers on it, before or after maps appear:

<Code code={region(examples, "resource-transform")} lang="ts" />

For other rewrites, pass a `callback` instead of `rules`; it must answer every
request. On OpenHarmony, FFI has no header transform: serve the requests that
need headers with `runtime.setResourceProvider()` instead. See FFI's [network
guide].

The default runtime, from <Api of="getDefaultRuntime" display="getDefaultRuntime()" />,
keeps its cache database, `maplibre-cache.db`, in the app's files directory, so
[offline regions] last between launches. The library owns the runtime's one
event handler, so watch a download with
<Api of="addRuntimeEventListener" display="addRuntimeEventListener()" />:

<Code code={region(examples, "offline")} lang="ts" />

A listener gets the runtime's own events, such as offline progress, and only the
map events that it asks for. The library sets each map's event mask to what the
listeners ask for, so a map's other events cost nothing:
