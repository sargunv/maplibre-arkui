Maps load their styles, tiles, fonts, and icons through a
<Api of="MapRuntime" />, which holds the cache and decides how each request
loads. Every map and snapshot uses the default runtime unless you pass another.

## Rewrite URLs

To add an API key to tile URLs, give the default runtime a `rewriteUrl`
function with
<Api of="MapRuntime.configureDefault" display="MapRuntime.configureDefault()" />.
Call it before the first map appears, such as in your ability's `onCreate()`:
