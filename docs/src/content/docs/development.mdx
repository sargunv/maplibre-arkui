---
title: Build from source
description: Build the library, the demo, and this site, and run the tests.
---

[mise] installs every tool, including the OpenHarmony SDK and an Oniro emulator
image:

```sh
mise install
mise run demo    # build the demo and start it on an emulator
mise run test    # run the hypium suite on the emulator
mise run check   # run every formatter and linter
```

`mise tasks` lists the other tasks. `--device <key>` runs the demo or the tests
on another device, such as DevEco Studio's emulator. Both bundle FFI's OpenGL
backend; `--backend vulkan` bundles the Vulkan backend instead, which the Oniro
emulator has no driver for.

`mise run docs:dev` serves this site with the API reference. The site's code
examples are regions of the demo's [`ets/docs/`][examples] files, so the demo
build compiles them, and the site build fails if a region is missing.

Before you change the public API, read the
[API guidelines](/maplibre-arkui/api-guidelines/). [AGENTS.md] has the rest of
the guidance for contributors.
