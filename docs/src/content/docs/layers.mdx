To draw your own data, you add a source and at least one layer. A source holds
data, such as points, lines, or shapes. A layer draws the data from one source
in one way, for example as circles or lines. You declare both in a
<Api of="MapContent" /> and pass it to the map as `content`.

## Draw GeoJSON data

A `@Computed` getter builds the content from your component's state. This
example draws a circle for each place:

<Code code={region(layers, "geojson")} lang="ts" />

<Api of="color" display="color()" /> takes any ArkUI color, such as
`Color.Red` or `$r('app.color.place')`. A resource color changes with the
system's dark mode.

Sources and layers take the same JSON as a style document, so the
[MapLibre Style Specification][spec] lists every source type, layer type, and
property. Layers draw in the order that you list them. The content stays on the
map when the style changes.
