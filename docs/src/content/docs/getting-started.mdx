MapLibre ArkUI needs API 20 or later and ArkUI's state management V2.

## Install the library

The library isn't on ohpm yet. Until it is, build it from this repository; see
[Build from source](/maplibre-arkui/development/). Once it's published, install
it with a rendering backend of MapLibre Native FFI:

```sh
ohpm install @maplibre/arkui @maplibre/native-ffi-opengl@<FFI version>
```

The backend's version must match the version of `@maplibre/native-ffi` that
`@maplibre/arkui` depends on, which `ohpm list` shows.

## Request permissions

The library declares no permissions. To load styles and tiles from the network,
declare these in your app's `module.json5`. With the second one, maps wait for a
connection instead of failing while the device is offline.

```json5 title="module.json5"
"requestPermissions": [
  { "name": "ohos.permission.INTERNET" },
  { "name": "ohos.permission.GET_NETWORK_INFO" }
]
```
