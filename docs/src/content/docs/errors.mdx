## Handle map errors

When something fails on the map with no call to reject, such as a style that
doesn't load, the map passes a <Api of="MapError" /> to its
<Api of="MaplibreMap.onError" display="onError" />. Check its class to tell the
kinds apart, and keep a fallback for the others:
