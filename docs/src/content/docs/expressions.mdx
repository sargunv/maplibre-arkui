An expression computes a value for each feature, or for the current zoom level.
Layers use expressions in their `filter`, `paint`, and `layout`. The
[MapLibre Style Specification][spec] lists every operator.

## Write an expression

Each operator has a function with its name, such as <Api of="get" />,
<Api of="match" />, and <Api of="interpolate" />. Operators written with symbols
get words instead, such as <Api of="eq" /> for `==` and <Api of="add" /> for
`+`. `case` is <Api of="cases" />, and `feature-state` is
<Api of="featureState" />.

<Code code={region(expressions, "expressions")} lang="ts" />

Wrap array and object values in <Api of="literal" display="literal()" />, since
a bare array reads as an expression.

Write colors with <Api of="color" display="color()" /> and icons with
<Api of="image" display="image()" />.
