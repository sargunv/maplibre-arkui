For everything else, the style API is MapLibre Native FFI's: `controller.map`, a
<Api of="MapHandle" />, adds and changes sources, layers, images, and feature
state, and `controller.renderSession`, a <Api of="RenderSessionHandle" />,
queries features, such as the base style's near a click. A click's point is in
vp from the map's corner, as queries take it. The content's own layers take
[clicks](/maplibre-arkui/gestures/#clicks) without a query.

What an app adds through `controller.map` is gone in the next style, so add it
in `onStyleLoaded`, or declare it as [content](/maplibre-arkui/content/). Change
the style through the map's `style`, not the FFI map's style setters, so the map
adds its content again. On an idle map, a feature state change draws only from
the frame after the one that applies it; until FFI fixes that, request one, as
the demo's style page does with `map.discarding.requestRepaint()` from a delayed
frame callback ([maplibre-native-ffi#1706]).

[maplibre-native-ffi#1706]: https://github.com/maplibre/maplibre-native-ffi/issues/1706
