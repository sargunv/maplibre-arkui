## Change the style

The controller's <Api of="MapController.style" display="style" />, a
<Api of="MapStyle" />, reads and changes the style that the map has loaded: its
sources, layers, images, global state, transition, and light. It works from the
map's `onStyleLoaded` until the next style; before then, its reads resolve
`undefined` and its writes `false`. What the app keeps in its state belongs in
the map's [content](/maplibre-arkui/content/) instead, which the map adds to
each style.

### Layers

<Api of="MapStyle.getLayer" display="getLayer()" /> and
<Api of="MapStyle.getLayers" display="getLayers()" /> give a
<Api of="LayerHandle" /> for each layer of the base style and the content, from
bottom to top. A handle reads and sets the layer's layout and paint properties,
their transitions, its filter, and its zoom range, and `null` restores a
property's default. To change the base style's own layers, such as to recolor

<Api of="MapStyle.getSources" display="getSources()" /> give a
<Api of="SourceHandle" /> for each source of the style. A
<Api of="GeoJsonSourceHandle" /> replaces its source's data or URL, and keeps
the source's options, such as its clustering. An
<Api of="ImageSourceHandle" /> replaces its source's image, URL, or corners.

Declare the sources that the app defines, and the data that it keeps in its
state, as content, which the map adds to each style before the layers that
draw them. <Api of="MapStyle.addSource" display="addSource()" /> adds a source
to the loaded style alone, for one that depends on what that style has, which
the app adds in `onStyleLoaded` after it reads the style. Until it's in, a
content layer that draws it fails with a `ContentError`.

### Feature state

Feature state gives a feature of a source values by name, which paint
properties read with <Api of="featureState" display="featureState()" />, such
as to highlight the feature that a click selects. It works on every source,
the base style's and the content's too. A <Api of="GeoJsonSourceHandle" />'s
<Api of="GeoJsonSourceHandle.setFeatureState" display="setFeatureState()" /> merges
values into a feature's state, and its
<Api of="GeoJsonSourceHandle.removeFeatureState" display="removeFeatureState()" /> removes
them; a <Api of="VectorSourceHandle" />, from
<Api of="MapStyle.getVectorSource" display="getVectorSource()" />, does the same
in one of its source layers. A feature state method takes the feature's `id`,
and the change draws on the next frame. The map applies the changes in
the order that the app sends them, so take the handle in `onStyleLoaded`, and
send a click's changes without awaiting between them:

### Clusters

A GeoJSON source with `cluster` set groups nearby points into cluster features,
which have a `cluster_id` property. A <Api of="GeoJsonSourceHandle" /> reads a
cluster: the zoom at which it splits, the clusters and points that it splits
into, and the points that it holds. Each resolves `undefined` for a feature that
isn't one of the source's clusters. A click on a cluster can zoom in until it

### Images

<Api of="MapStyle.setImage" display="setImage()" /> adds a
<Api of="StyleImage" /> to the style, or replaces the sprite's image with its
ID, and <Api of="MapStyle.removeImage" display="removeImage()" /> removes one.
It copies the pixels as it's called, so the app can release the pixel map
after.

### Transition and light

<Api of="MapStyle.setTransition" display="setTransition()" /> sets how long the
style's properties take to change, and
<Api of="MapStyle.setLightProperty" display="setLightProperty()" /> sets a
property of the light, as the style spec writes it. Like a layer's
`setProperty()` and `setGlobalStateProperty()`, it takes `null` to restore the
property's default.

## Who owns an ID

The content owns the IDs of its sources, layers, and images. The style API
reads them, but its writes throw for them, except those of feature state: change
the content instead. A handle's `fromContent` says whether its layer or source
is the content's, so a loop over `getLayers()` can skip them. When the
content declares the ID of a source that the app added, the content's source
replaces it. The library reserves the IDs that start with `maplibre-arkui`,
such as the user location indicator's, and the global state names that start
with `maplibre-arkui:`, such as the one that <Api of="fp" display="fp()" />
reads: reads leave them out, and writes throw.

## What the next style keeps

A new style starts from its own document. It doesn't keep what the app changed
through the style API or the FFI map, such as a source it added or a property it
set, and the handles of the last style expire. A new `style` value, a map that
appears again, and a map that starts again at a new display density each load a
new style. Make the changes again in `onStyleLoaded`, or declare them as
content.

Feature state is the map's, not the style's: a source of the next style with
the same ID shows the state that the app set, until the app removes it, such
as with <Api of="GeoJsonSourceHandle.resetFeatureStates" display="resetFeatureStates()" />.
A map that appears again, or starts again at a new display density, starts
without it.

## The FFI map

For what the library doesn't cover yet, such as debug overlays, the
controller's <Api of="MapController.withFfiMap" display="withFfiMap()" /> lends
a callback the FFI map, a `MapHandle`, and its render session, a
`RenderSessionHandle`. Their API is MapLibre Native FFI's: see its [TypeScript
reference]. Import their types from `@maplibre/native-ffi`, at the version that
the library depends on. The callback runs at once, so send the map's commands
in it, and await their promises after it returns:

<Code code={region(examples, "ffi-map")} lang="ts" />

Don't change what the library owns through the FFI map: the style, the
content's sources, layers, and images, the camera padding, the camera bounds,
the runtime's event handler, and the map's event mask.
