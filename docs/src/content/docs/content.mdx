An app declares what it draws over the style as data: sources, layers, and
images, in a <Api of="MapContent" /> that it passes to `MapLibreMap`. A
`@Computed` getter that reads the app's state makes a new value when the state
changes, and the map compares it with what it applied, by ID, and changes only
what differs: a property in place, a GeoJSON source's data, a layer's position.
Each style the map loads gets the content again, so it lasts across style
changes.

<Code code={region(examples, "content")} lang="ts" />

The map takes it as `content`, as in
[the style API](/maplibre-arkui/style/)'s example.

To change it, give the state a new value; the map doesn't see changes made
inside a value it has. It compares properties and GeoJSON data by their JSON,
and images by reference, so read an image once:

Strict ArkTS takes an object literal only for a declared type, so the library
declares GeoJSON's types (<Api of="GeoJsonFeatureCollection" />,
<Api of="GeoJsonFeature" />, <Api of="GeoJsonGeometry" />), and style JSON is a
`Record<string, Object>` with quoted keys:

<Code code={region(examples, "geojson")} lang="ts" />

Layers go on top, or under the layer that `below` names or picks, in their order
in `layers`, and their `onClick` and `onLongClick` handle
[clicks](/maplibre-arkui/gestures/#clicks) on their features. A string names a
base-style layer or another content layer, and a predicate picks a base-style
layer. Text sizes in <Api of="fp" display="fp()" /> follow the user's font size
setting as ArkUI's `fp` sizes do, once the app opts in with
`"fontSizeScale": "followSystem"` in its [configuration profile]; the base
style's labels don't. A source or layer that the map rejects goes to
`onMapError` and stays out until it changes. <Api of="readPixelMap" display="readPixelMap()" />
turns a decoded `PixelMap` into a style image; the demo's [`readImage()`] reads
one from `resources/rawfile`.
