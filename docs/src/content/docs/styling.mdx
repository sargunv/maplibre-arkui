A style is a JSON document that tells the map what to draw. It lists the data
sources, such as vector tiles, and the layers that draw that data: roads, water,
buildings, and labels. The format is the [MapLibre Style Specification][spec].

## Choose a style

You usually get a style from a map tile provider, which serves the style and the
tiles it uses. The [awesome-maplibre] list names free and commercial providers.
The examples in this documentation use [OpenFreeMap], which needs no account. To
design your own style, edit one in [Maputnik].
